# 🇷🇸 База цен в Сербии

Личный мини-проект (для 2–3 человек): база цен на товары в магазинах Сербии
плюс общий список покупок. Просмотр базы доступен всем, редактирование базы —
через админку с паролем. Список покупок может менять любой.

**Скриншот:** _добавь сюда скрин_

## Технологии

- Чистые HTML5, CSS3 и Vanilla JavaScript (ES-модули). Без фреймворков и сборщиков.
- База данных: **Supabase** (Postgres + REST).
- Хостинг: **GitHub Pages** (только статика).
- Клиентский кэш: **localStorage** (мгновенный старт и оффлайн-чтение).

## Установка

### 1. Создай проект в Supabase
Зарегистрируйся на [supabase.com](https://supabase.com) и создай новый проект (бесплатного плана хватает).

### 2. Выполни SQL
Открой в проекте **SQL Editor**, вставь содержимое файла `supabase.sql` и нажми **Run**.
Скрипт создаст таблицы `products`, `shopping_list`, `stores`, `categories`,
включит RLS-политики и добавит триггер автообновления `updated_at`.

### 3. Скопируй ключи
В Supabase зайди в **Settings → API** и скопируй:
- `Project URL` → это `SUPABASE_URL`;
- `anon public` key → это `SUPABASE_ANON_KEY`.

### 4. Заполни `js/config.js`
Открой `js/config.js` и вставь свои значения из Supabase → Settings → API.
Пароль админки (`ADMIN_PASSWORD`) поменяй на свой. При желании измени `EUR_RATE`.

```js
export const SUPABASE_URL = 'https://xxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
export const ADMIN_PASSWORD = 'твой_пароль';
export const EUR_RATE = 117.4;
```

### 5. Запусти локально
`file://` **не сработает** из-за ES-модулей — нужен статический сервер:

```bash
# Python 3
python -m http.server 8080

# или Node.js
npx serve .
```

Затем открой http://localhost:8080

## Как пользоваться

- **📊 База** (`index.html`) — просмотр всех цен, поиск и фильтры по магазину
  и категории. Работает без пароля. Показывает цены в RSD и EUR.
- **⚙️ Админка** (`admin.html`) — добавление, редактирование и удаление товаров,
  экспорт/импорт JSON и CSV, управление магазинами и категориями. Вход по паролю.
- **🛒 Список покупок** (`shopping.html`) — общий список: добавляй, отмечай
  купленное, редактируй текст по клику, удаляй. Доступен всем.

## Безопасность

⚠️ Пароль админки хранится в клиенте (`js/config.js`) и проверяется в браузере —
это **не настоящая защита**. RLS разрешает запись в `products` роли `anon`,
поэтому технически кто угодно с anon-ключом может писать в базу. Для личного
мини-проекта на 2–3 человек это осознанный компромисс. Для реальной защиты нужен
Supabase Auth и политики на основе ролей — см. комментарии в `supabase.sql`.
